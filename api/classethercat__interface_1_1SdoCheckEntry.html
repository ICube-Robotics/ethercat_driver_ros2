Detailed Description

One-shot SDO upload (read) + allowed-value validation, done once at configure time (before the master is activated). A slave whose read value isn't in allowed_values fails configuration outright — for hardware preconditions that must already be true on the physical drive (e.g. a commissioned sensor type), as opposed to SdoConfigEntry, which pushes a value onto the drive.
