Detailed Description

Per-slave AL state / link presence, as last observed by the master's periodic state check (throttled — see each master plugin's own check frequency). One entry per add_slave() call, in add order. Master-backend-agnostic: no ecrt.h/IgH types, so this survives swapping the master plugin (e.g. for a SOEM-backed implementation).
